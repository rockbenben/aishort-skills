# MD Web

Instant Markdown sharing — paste a link, read a beautifully rendered page.

即时 Markdown 分享 —— 打开链接，阅读排版精美的页面。

Both languages are shown side by side here so that either reader can use the page —
take whichever you prefer, neither is required, and the document you open is rendered
in the language it was written in.

两种语言在本页并排呈现，任何语言的读者都能直接使用 —— 随你选择，都不是必须的；
你打开的文档，按它原本写成的语言渲染。

## Looking for a document? / 找文档？

If you arrived here without a specific document, the link you need should look like:

如果你看到的是这个页面而非具体文档，你需要的链接格式应该是：

```
https://your-domain/index.html#/md-web/20260903-091500-your-document
```

Check the link you received and make sure the `#/document-name` part is included.

请检查你收到的链接，确保包含 `#/文档名` 部分。

## Features / 功能

- **Full-text search / 全文搜索** — search within the current document / 搜索当前文档内容
- **Table of contents / 目录导航** — auto-generated from headings, shown on screens wider than 1300px / 根据标题自动生成，宽度超过 1300px 的屏幕才显示
- **Image zoom / 图片缩放** — click any image to view full size / 点击图片查看原图
- **Word count / 字数统计** — reading time estimate / 自动估算阅读时间

## About this page / 关于本页

Rendered by [MD Web](https://github.com/rockbenben/aishort-skills/tree/main/skills/md-web).
It loads Markdown only from its own bucket, and a link whose route points anywhere else
is refused rather than rendered. Documents are rendered as HTML, so read a published page
as untrusted content — never enter credentials into a page you did not expect to be this one.

本页由 [MD Web](https://github.com/rockbenben/aishort-skills/tree/main/skills/md-web) 渲染：
只加载自家存储桶里的 Markdown，任何指向别处的文档路由都会被拒绝而不是照常渲染。
文档按 HTML 渲染，所以请把已发布页面当作不可信的内容来阅读 —— 除非你本就预期看到这个页面，
否则不要在其中输入任何凭证。
